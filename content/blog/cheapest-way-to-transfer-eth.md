Transferring Ethereum (ETH) between crypto exchanges can be surprisingly expensive on the native ERC-20 network. Gas fees fluctuate wildly and can eat into your trading profits. Here is how to find the cheapest transfer route every time.

## Native ETH (L1) Withdrawal Costs

Withdrawing ETH on the main Ethereum network (Layer 1) costs:

- **Binance:** 0.00028 ETH (~$0.98)
- **OKX:** 0.0004 ETH (~$1.40)
- **Kraken:** 0.0015 ETH (~$5.25)
- **Coinbase:** Dynamic (~$1.50–$5.00)
- **KuCoin:** 0.003 ETH (~$10.50)

These are exchange-set fees and do not include network gas, which the exchange pays on your behalf.

## Layer 2 Options (Much Cheaper)

Several exchanges now support ETH withdrawals on Layer 2 networks:

### Arbitrum
- **Binance:** 0.00015 ETH (~$0.52)
- **OKX:** 0.0001 ETH (~$0.35)
- Confirmation time: 1–5 minutes

### Optimism
- **Binance:** 0.00015 ETH (~$0.52)
- **OKX:** 0.0001 ETH (~$0.35)
- Confirmation time: 1–5 minutes

### Base
- **Coinbase:** ~$0.10 (Coinbase's own L2)
- Limited support on other exchanges

## The Smart Strategy

For ETH transfers between exchanges:

1. Check if both exchanges support the same L2 network (Arbitrum is the most widely supported)
2. If yes, use that L2 — you will save 70–90% compared to L1
3. If no shared L2, compare native L1 fees and pick the cheaper exchange to initiate from

## When L2 Is Not Available

If neither exchange supports L2 for ETH:

- Consider converting ETH to SOL, transferring (fee: ~$0.01), then converting back
- Use our [ETH withdrawal fee checker](/cheapest-withdrawal/eth) to find the current cheapest option

## Avoid These Mistakes

- **Do not send L2 ETH to an L1 address** (unless the exchange specifically supports it)
- **Always verify the network** matches on both the sending and receiving side
- **Watch for minimum withdrawal amounts** — some exchanges require 0.01+ ETH minimum
